## Overview

This repository contains the completed Week 1 Practical Laboratory assessment based on the GlobalHealth Connect (GHC) Information Security Governance simulation.

The assessment focuses on designing governance structures, establishing accountability, developing governance artefacts, reporting security metrics, and evaluating governance maturity.
