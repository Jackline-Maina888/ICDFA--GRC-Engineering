
# Evidence Bundle 2 – Governance Responsibility Matrix

## Objective
To define governance responsibilities, authority, reporting lines, and accountability for key stakeholders involved in security governance.

## Evidence Included
- Cross-Functional Governance Responsibility Matrix
- Role Profiles / Responsibility Cards
- Conflict Resolution Note

## Key Outcomes
- Established clear ownership of governance activities.
- Defined decision authority and reporting responsibilities.
- Created role profiles for Board, CEO, CISO, CRO, Legal, Finance, HR, and IT.
- Documented governance conflict resolution approaches.
