
# Evidence Bundle 1 – Governance Architecture & Stakeholder Analysis

## Objective
To assess weaknesses in the current governance structure and design an improved governance model that establishes clear accountability, risk oversight, and cross-functional collaboration.

## Evidence Included
- Governance Gap Assessment
- Stakeholder Map
- Security Governance Organisation Chart
- Consultant Justification

## Key Outcomes
- Identified governance weaknesses and accountability gaps.
- Mapped stakeholder authority, interests, and governance responsibilities.
- Designed a governance structure with Board oversight and executive accountability.
- Provided justification for the proposed governance model.
