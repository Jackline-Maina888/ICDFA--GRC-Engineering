
# Evidence Bundle 3 – Governance Committee Ecosystem

## Objective
To establish governance committees that provide oversight, decision-making, risk management, and accountability across the organisation.

## Evidence Included
- Executive Security Council
- Security Governance Committee
- Third-Party Risk Working Group
- Sample Governance Committee Agenda
- Sample Decision Log
- 12-Month Governance Calendar

## Key Outcomes
- Defined committee structures and responsibilities.
- Established governance meeting schedules.
- Created sample agenda and decision-tracking mechanisms.
- Developed an annual governance activity calendar.
