
GRC102 Practical Lab 8: Monitoring, Auditing Controls and Executive Reporting
Overview

This repository contains the deliverables, evidence, and supporting documentation for GRC102 Practical Lab 8. The exercise involved building a simulated Docker-based environment, analysing governance failures modelled on the Equifax breach, implementing governance controls, and producing executive reporting and governance metrics.

Objectives
Deploy an isolated Docker-based governance simulation environment
Analyse security and governance failures
Compare findings with the Equifax breach
Implement governance controls
Validate implemented controls
Produce governance metrics and executive reporting
Environment Components
Apache Struts 2.3.30 Web Application
MySQL Database Server
Governance Monitoring Server
Governance Tracking Dashboard
Security Governance Metrics Framework
