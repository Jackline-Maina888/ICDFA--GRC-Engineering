# Task 1: Security Policy Hierarchy

## Objective
Establish a security documentation hierarchy and classify security statements into the appropriate document types.

## Deliverables
- Hierarchy Definition Table
- Categorisation Table
- Policy Hierarchy Diagram

## Key Concepts
- Policy
- Standard
- Procedure
- Guideline

## Outcome
A structured security governance framework was developed showing how policies, standards, procedures, and guidelines support information security management.


# Task 2: Acceptable Use Policy (AUP)

## Objective
Develop an Acceptable Use Policy for NexusTech Solutions to define acceptable and prohibited use of company resources.

## Deliverables
- Document Control Information
- Purpose and Scope
- Acceptable Use Requirements
- Prohibited Activities
- Roles and Responsibilities
- Compliance and Enforcement
- Exceptions Process
- Approval and Review Requirements

## Outcome
A formal policy was created to promote secure and responsible use of organizational systems, devices, and information assets.


# Task 3: User Access Request Procedure

## Objective
Develop a documented procedure for requesting, approving, provisioning, and reviewing user access.

## Deliverables
- Purpose and Scope
- Prerequisites
- User Access Workflow
- Emergency Access Process
- Record Retention Requirements

## Procedure Overview
1. Request Submission
2. Approval Verification
3. Access Validation
4. Account Creation
5. Permission Assignment
6. User Notification
7. Evidence Capture
8. Ticket Closure

## Outcome
A repeatable and auditable process was established to ensure secure and controlled access management.
