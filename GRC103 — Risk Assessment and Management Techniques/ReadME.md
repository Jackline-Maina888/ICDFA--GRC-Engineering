# Lab 1: Practical Vulnerability Assessment for GRC Professionals

## Objective

Perform a vulnerability assessment on a Metasploitable server and evaluate findings from a Governance, Risk, and Compliance (GRC) perspective.

## Tools Used

- Nmap
- Nikto
- Nuclei
- xsltproc

## Assessment Activities

1. Asset Discovery
2. Port and Service Enumeration
3. Vulnerability Identification
4. Risk Assessment
5. Compliance Mapping
6. Executive Reporting

## Repository Structure

- scans/ --> Raw scan outputs
- screenshots/ --> Evidence and screenshots
- report/ --> Final assessment report
